# ケアタイムライン（Care Timeline）
### 介護の「見えない時間」可視化 × 保険外サービス横断検索

> **「介護サービスを検索するプロダクトではなく、家族が失っている時間を可視化し、それを買い戻す方法を提示するプロダクト。」**

---

## 🏆 プロダクト概要

高齢の親族を介護する家族が、要介護度・世帯状況・困りごとを入力すると、**1週間のケアタイムライン（7日×4時間帯=28スロット）** が生成されます。誰が・いつ・何をしているかがマス目で描かれ、家族が自力で抱えている時間が**赤色**で浮き彫りになります。

**「サービスを当てはめる」** ボタンひとつで、公的介護保険給付・総合事業・自治体独自施策・民間の自費サービスが最適配置され、赤が減っていきます。同時に**「家族の介護時間（h/週）」**と**「自己負担額（円/月）」**が連動し、**「いくら払えば何時間が戻ってくるのか（時間の買い戻し単価）」**が一目で分かります。

裏側では、自治体の公開情報や公表システムからAIが自動収集・構造化したデータベースが稼働し、検索して0件だった需要は匿名ログとして蓄積され、自治体向けの「サービス空白ヒートマップ」に集計されます。

---

## 🎯 解決する課題

1. **家族の課題**: どんな保険外サービスがあるか知らない／自分が何時間介護に使っているか自覚がない
2. **ケアマネジャーの課題**: 保険外サービスを案内する報酬上のインセンティブがなく、境界説明に労力がかかる
3. **自治体（to G）の課題**: 総合事業や生活支援体制整備事業において、どの地域・時間帯に未充足需要があるか把握できていない

## 💡 中核ロジック ＆ 技術的挑戦

### 1. 予算制約付き 効率順貪欲法（最適化エンジン）
$$\text{Efficiency} = \frac{\text{削減家族時間 (reduction\_hours)}}{\text{1回あたり自己負担額 (cost)}}$$
- 保険給付は要介護区分ごとの区分支給限度基準額（単位数上限）を遵守し、超過分は10割負担として計算。
- 予算 $B$ 円の制約下で削減時間を最大化する最適割り当てを **100ms以内** で返却。
- 予算0円の場合は、無償ボランティア・互助サービス・自治体無料施策のみで自動構成。

### 2. 「時間の買い戻し単価」の提示
$$\text{買い戻し単価} = \frac{\text{追加自己負担額／月}}{\text{削減された家族時間／月}}$$
- 介護を「コスト」と呼ばず、「1週間のうち〇時間を、あなたが支えています」と温かい表現を徹底。

### 3. AI構造化 ＆ 出典管理
- 料金・対象条件は原文抜粋（`price_source_snippet`）と出典URLを保持し、推測による穴埋めを禁止。
- 承認済みシードデータ150件以上（うち保険外80件以上）を内包。

## 🛠 技術スタック

- **フロントエンド**: Next.js 16 (App Router) + TypeScript + Tailwind CSS (v4)
- **アニメーション**: CSS Transition (0.35s) + `requestAnimationFrame` カウントアップ
- **アイコン**: Lucide React + Canvas Confetti
- **バックエンド / API**: Next.js API Routes (Route Handlers)
- **データ収集**: Python 3 + Claude Structured Output
- **印刷**: Print CSS (A4 1枚最適化)

## 🎬 5分間ピッチ・デモ台本

1. **0:00 - 0:30 【赤いタイムライン】**:
   「これは実在の家族の1週間です」。説明せず、家族が自力で抱えている真っ赤な週42時間のタイムラインを見せる。
2. **0:30 - 1:00 【時間を買い戻す】**:
   「サービスを当てはめる」ボタンをクリック。0.35秒で赤が消え、「月2.5万円で、週23時間が戻りました。1時間あたり約570円です」と提示。
3. **1:00 - 1:30 【予算0円の力】**:
   予算スライダーを0円まで下げる。「0円でもここまで減らせます。知らないだけで、地域には使える無償・互助施策があります」。
4. **1:30 - 3:00 【AI収集と信頼性】**:
   AI収集・承認コンソールを見せ、公開情報からAIが構造化し、人手が確認したもののみを掲載する仕組みを説明。
5. **3:00 - 4:30 【自治体の空白ヒートマップ】**:
   自治体ダッシュボードへ遷移。「平日夕方に需要が集中しているのに、対応事業者がゼロ。検索0件のログが自治体の政策立案データになります」。
6. **4:30 - 5:00 【結び】**:
   ケアマネジャーの報酬構造の限界を超え、市民が自力で辿り着けるインフラを創るというビジョンで締める。
